## Important Decisions
- **Anti-Hardcoding Rule**: AODV will be implemented logically via RREQ/RREP propagation, explicitly avoiding graph algorithms like Dijkstra or BFS for routing logic.
- **Architecture Progression**: Strict adherence to building the networking engine models and logic *before* any API, DB, or UI layer is introduced.
- **Separation of Concerns**: Simulated networking (routing, topology) will remain cleanly separated from eventual real networking (UDP/TCP sockets).
- **Phase 1 Constraints**: Strict restriction on implementing *only* the baseline models and static routing. No dynamic routing (AODV) or external frameworks yet.
