- Comprehensive test suite covering Phase 1, Phase 2, and Phase 3 functionalities with 107 passing tests.

## Important Decisions
- **Anti-Hardcoding Rule**: AODV was implemented logically via RREQ/RREP propagation. No graph algorithms like Dijkstra or BFS were used. Routes emerged organically.
- **Disaster Resilience**: AODV fully supports route invalidation via sequence number increments and RERR propagation when link or node failures are detected, seamlessly followed by organic route rediscovery.
- **API Boundary**: FastAPI serves only as an interface wrapping the existing SimulationEngine. Routing logic remains completely inside the core engine.
- **Frontend Decoupling**: React acts solely as a visual client and state renderer; no routing logic lives in React.
