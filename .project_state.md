## Important Decisions
- **Anti-Hardcoding Rule**: AODV was implemented logically via RREQ/RREP propagation. No graph algorithms like Dijkstra or BFS were used. Routes emerged organically.
- **Genuine Network-Level ACKs**: ACKs are actual DATA packets traversing the routing and transport pipelines; no direct function calls or simulated UI fake ACKs.
- **Two-Laptop Distributed Independence**: Hospital-H runs independently on Laptop 2, receiving genuine UDP datagrams, recording SOS in its own processed message store, and emitting network-level ACKs across the LAN interface back to Laptop 1.
- **API Boundary**: FastAPI serves only as an interface wrapping the active runtime. Routing logic remains completely inside AODV routers.
- **Frontend Decoupling**: React acts solely as a visual client and state renderer; no routing logic lives in React.
- **Transport Independence**: Routing relies strictly on the injected Transport module.
- **Security / Untrusted Data**: Serialized packets are validated; process management uses strictly sanitized, predefined parameters.
