## Important Decisions
- **Anti-Hardcoding Rule**: AODV was implemented logically via RREQ/RREP propagation. No graph algorithms like Dijkstra or BFS were used. Routes emerged organically.
- **Disaster Resilience**: AODV fully supports route invalidation via sequence number increments and RERR propagation when link or node failures are detected, seamlessly followed by organic route rediscovery.
